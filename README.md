# HSK-GraphRAG

Companion repository for the paper **Cyber-Physical GraphRAG: Safe, Real-Time, and Scalable Orchestration of Large-Scale Autonomous Fleets**, published in IEEE Access, vol. 14, pp. 107177-107195, 2026.

Paper: [doi:10.1109/ACCESS.2026.3706610](https://doi.org/10.1109/ACCESS.2026.3706610)

## Contents

| Path | What it is |
|---|---|
| `experiments/benchmark_data/benchmark_results.json` | Benchmark results |
| `experiments/results.log` | Run log |
| `experiments/verfiy_results.py` | Script to verify the results |
